Kuetix Engine CLI - Kue

Usage: kue [global-options] <command> [subcommand] [options]

LOCAL — work on files in the current project / machine, no network:
  create       Create a new application/project from a template
  add          Add a module, workflow, feature, solution, package, or transition
               Subcommands: module, workflow, feature, solution, package, transition
  update       Regenerate the module cache (di.go, meta.go, modules.json)
  show         List apps, solutions, features, workflows, modules in the project
  inspect      Show a workflow's source, provenance, dependencies, and actions
               (resolves a local file, ./workflows, or the ~/.kue cache)
  run          Execute a workflow — a local .wsl/.swsl file, a project dir, or a
               registry name (fetched + verified + cached).  Alias: r
  modules      List the packages compiled into this kue binary.  Alias: m
  transitions  List every action a workflow can call here.  Alias: t

REGISTRY (api.kuetix.com) — find, fetch, publish, manage:
  wsl <query>  Search published workflows.  `--search` forces search on a word
               that names a command.
  get          Fetch a workflow + its Go deps into the project; idempotent
               (installs, or refreshes an existing copy).  Also: install / i
  upload       Publish local workflows (all, or a name/glob).  --public lists
               them in the open registry.
  list         List workflows owned by the authenticated user
  status       Compare local workflows against the server
  delete       Delete a workflow on the server
  package      Look up a package (`kue package <name>` / `package search
               <query>`), or manage package deps + publishing.
               Subcommands: search, get, add, update, install, list,
                            list-local, enable, publish, show
  login        Authenticate and store the login payload
  logout       Remove the stored login payload
  register     Register a new Kuetix account
  whoami       Show the currently authenticated identity
  profile      Manage the authenticated user profile.  Subcommands: get, update

OTHER:
  completion   Output a shell completion script.  Subcommands: bash, zsh
  templates    Manage the .kue/templates cache
               Subcommands: download, update, clear, status
  help         Show this help, `kue help examples`, or `kue help env`

get / inspect / status / upload / list / delete are also spellable with a
`wsl ` prefix (`kue wsl get …`).

Global Options:
  -v, --verbose              Verbose output
      --debug                Debug output
  -q, --quiet                Quiet mode
  -h, --help                 Show help for a command or subcommand
      --modules <path>       Path to the modules directory (default: modules)
      --workflows <path>     Path to the workflows directory (default: workflows)
  -H, --host <host>          API host (default: api.kuetix.com)
  -c, --config <path>        Path to the config file

Global Template Options:
  --template-url <url>       URL to fetch templates from
                             (default: https://templates.kuetix.com/latest/)
  --template-version <ver>   Template version, e.g., 0.1.0 (default: latest)
  --template-path <path>     Local directory path for templates
  --template-git <url>       Git repository URL for templates

Template Priority: local path > git > web URL

More help:
  kue help examples            Common command examples
  kue help env                 Environment variables
  kue <command> --help         Help for a specific command
  kue <command> <sub> --help   Help for a subcommand
