kue — environment variables

  KUE_HOST                   Default API host (overridden by --host / -H)
  KUE_CONFIG_PATH            Default path to config file (overridden by --config / -c)
  KUE_TEMPLATE_URL           Default template URL
  KUE_TEMPLATE_VERSION       Default template version (e.g. 0.1.0)
  KUE_TEMPLATE_PATH          Default local templates directory
  KUE_TEMPLATE_GIT           Default template git repository

Template source priority: local path > git > web URL
